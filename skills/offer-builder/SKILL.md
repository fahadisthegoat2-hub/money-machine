# Offer Builder

Produce a one-page offer. Keep it short.

1. **Niche:** who exactly (e.g. "Minecraft server owners", "Riyadh dental clinics").
2. **Painful problem:** one sentence in the customer's words.
3. **Promise:** outcome + timeframe ("Pro server trailer in 72 hours").
4. **Deliverables:** 3–5 concrete items, fixed scope.
5. **Pricing:** Starter / Standard / Premium. Mark the middle as "most popular".
6. **Risk reducer:** honest guarantee (e.g. one free revision round). No fake claims.
7. **Proof:** use real portfolio pieces; if none, make 1 free/cheap sample for a target client.
8. **CTA:** one action ("Reply 'trailer' and I'll send a sample").

Output: offer one-pager + 1 cold DM + 1 follow-up DM, ready to paste.
