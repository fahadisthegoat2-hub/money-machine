# Money Machine

Claude plugin that makes Claude a revenue-focused operator.

**Skills:** `money-machine` (playbook) · `offer-builder` · `cash-sprint` (7-day plan to first sale)
**Prompt:** see [PROMPT.md](PROMPT.md)

## Install
```
/plugin marketplace add <owner>/money-machine
/plugin install money-machine@money-machine-marketplace
```

No plugin can guarantee income. It makes Claude faster at finding, pitching and closing real customers.
